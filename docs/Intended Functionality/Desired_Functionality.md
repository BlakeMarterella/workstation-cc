# Desired Functionality

I want to be able to run this command when I first get a new machine and have it set everything up. A vast majority of the time, I will be using it for MacOS machines, but there will be sometimes when I need to use it on a linux machine (either a full GUI installation, like using Ubuntu desktop or an Arch variant, or sometimes it will just be on a CLI server).

## Interface

I want to be able to run a single command to start the install process.

Ex (from root):

```
git 
```
